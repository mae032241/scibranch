# SciBranch changelog

## Unreleased

- Publish the project as [SciBranch](https://github.com/mae032241/scibranch),
  retaining the `scidiscovery` Python package and `scid-*` command names.
- Provide instance-oriented research through `scid-research`, managed execution
  through `scid-experiment`, and an on-demand instance UI.
- Preserve exact input and implementation identities, finite budgets, sealed
  results and same-call recovery across scientific work.
- Keep domain algorithms in runtime Skills and execution adapters in optional
  plugins, with shared compiler declarations and schemas available as libraries.
- Publish current references and functional fixtures through an explicit source
  release manifest; keep development skills, plans, audits and trial outputs local.
- Consolidate native usage audit guidance in [tests/README.md](tests/README.md)
  and TCAD qualification boundaries in the [plugin guide](plugins/tcad_artifact/README.md#qualification-boundary).

Supported behavior and qualification boundaries are documented in
[release scope](docs/RELEASE.md) and [architecture](docs/ARCHITECTURE.md).
